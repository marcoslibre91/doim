Import dati

Due modi per far entrare i dati senza digitarli a mano: un CSV (utile per i report esportati dai network) o l'API per i connettori automatici. I segnali vanno definiti prima a mano (per tenerne stabile il significato); opportunità e fonti mancanti si creano da sole.

CSV di osservazioni

Colonne richieste: opportunity_key, signal_key, value, observed_at, source. Le opportunità e le fonti mancanti vengono create; i segnali NO — la semantica dei segnali si definisce a mano, versionata (§7).

Report dei network (GiddyUp & co.)

GiddyUp e molti network "pro" girano su piattaforma Everflow: dal pannello affiliato puoi generare una API key personale e usare app/connectors.py per scaricare offerte e statistiche del TUO account (uso legittimo: solo i propri dati, via API ufficiale). In alternativa esporta i report CSV dal pannello e riconducili al formato qui sopra.

API bulk per connettori: POST /api/observations con lista JSON [{"opportunity_key":..., "signal_key":..., "value":..., "observed_at":..., "source":...}].
