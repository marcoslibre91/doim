Import dati

Tre modi per far entrare i dati senza digitarli a mano: Incolla offerte (il più veloce — copia dal pannello del network), un CSV (per i report esportati) o l'API per i connettori automatici (incluso Apify). I segnali vanno definiti prima a mano (per tenerne stabile il significato); opportunità e fonti mancanti si creano da sole.

CSV di osservazioni

Colonne richieste: opportunity_key, signal_key, value, observed_at, source. Le opportunità e le fonti mancanti vengono create; i segnali NO — la semantica dei segnali si definisce a mano, versionata (§7).

Report dei network (GiddyUp & co.)

GiddyUp e molti network "pro" girano su piattaforma Everflow: dal pannello affiliato puoi generare una API key personale e usare app/connectors.py per scaricare offerte e statistiche del TUO account (uso legittimo: solo i propri dati, via API ufficiale). In alternativa esporta i report CSV dal pannello e riconducili al formato qui sopra.

API bulk per connettori: POST /api/observations con lista JSON [{"opportunity_key":..., "signal_key":..., "value":..., "observed_at":..., "source":...}].

Ad library & Apify (creativi concorrenti)

Gli annunci dei concorrenti si aggiungono a mano dalla scheda di ogni opportunità (sezione Campagne concorrenti), oppure in bulk quando vorrai scalare. Il sistema è Apify-ready: l'output JSON di un actor «Meta Ad Library» (o simile) entra direttamente da POST /api/creatives:

[{"opportunity_key":..., "advertiser":..., "first_seen":..., "last_seen":..., "active":true, "format":..., "angle":..., "source":"Apify (ad library scraper)"}]

Da questi il sistema calcola da solo densità, longevità e nuovi advertiser. Consiglio del comitato: attiva Apify solo dopo aver validato a mano che la longevità predice qualcosa (ipotesi A14) — prima pagheresti per raccogliere rumore.
